# Autonomy checklist

La autonomía no es "saber mucho", es poder **hacer** sin depender de la IA.
Marca evidencia real, no intención.

## Escalera de maestría
1. **Reproducir:** rehacer lo existente sin mirar.
2. **Extender:** añadir una feature siguiendo los patrones.
3. **Diseñar:** elegir arquitectura, modelo y tecnología con criterio.
4. **Depurar/operar:** diagnosticar con logs, métricas y tests.
5. **Enseñar:** explicarlo simple y revisar código de otros.

## Checklist por feature
- [ ] Puedo explicar el problema y el flujo en 3 minutos sin notas.
- [ ] Puedo diseñar la solución (capas, contratos, datos) sin IA.
- [ ] Puedo implementarla sin copiar.
- [ ] Escribí los tests (feliz, error, borde).
- [ ] Puedo depurar un fallo usando logs/tests.
- [ ] Escribí un ADR con tradeoffs.
- [ ] Usé la IA solo para revisar, no para resolver.
- [ ] Sé qué mejoraría en una segunda versión.

## Graduación
Considera que puedes trabajar sin IA cuando:
- Completas una feature nueva end-to-end sin referencias.
- Depuras sin adivinar.
- Justificas decisiones por escrito.
- Pides revisión, no solución.
